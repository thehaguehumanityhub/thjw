# Logos still missing

Drop a file into this folder with the **exact filename** below and it appears on the site.
Nothing else needs editing: the widget asks for `logos/<name>.png` for every organisation and
falls back to an initials tile when the file is not here.

- PNG, transparent background where possible.
- Roughly 160 px tall is plenty; wider than about 3:1 will look cramped.
- If a logo is white or very light and disappears on the white card, add
  `"d": 1` for that organisation in `overrides.json` to back it with the Hub navy.
